## Exercise 25 - Finding the Smallest of Three Positive Numbers

Write a program in which the user enters three positive numbers. The program should print the number with the smallest value. If all three numbers have the same value, print a message indicating that the three numbers are equal.

## Задача 25 - Пронаоѓање на најмалиот од три позитивни броеви

Да се напише програма со која корисникот на влез треба да внесе три позитивни броја, а на излез треба да се отпечати кој од броевите има најмала вредност. Доколку сите три броја имаат иста вредност треба да се отпечати порака дека станува збор за три исти броја.

**Input:**
