## Exercise 2 - Basic Mathematical Operations

Write a C++ program that performs the basic mathematical operations (`+`, `-`, `*`, `/`, `%`) on two numbers read from standard input.

## Задача 2 - Основни математички операции

Да се напише програма која ќе ги изведува основните математички операции (`+`, `-`, `*`, `/`, `%`) врз два броја кои се читаат од стандарден влез.

## Test Cases


### Test Case 1

**Input:**
```text
24 5
```
**Expected output:**

```text
a + b = 29
a - b = 19
a * b = 120
a / b = 4
a % b = 4
```
