## Exercise 47 - Largest Three-Digit Number with an Even Digit Sum

### Problem Description

An integer `n` is entered through standard input, followed by `n` three-digit integers.

Your task is to find the largest number whose sum of digits is an even number.

### Input

- An integer `n`.
- `n` three-digit integers.

### Output

Print the largest three-digit number whose sum of digits is even.

---

## Задача 47 - Најголем трицифрен број со парен збир на цифри

### Опис на проблемот

Од стандарден влез се внесува цел број `n`, а потоа се внесуваат `n` трицифрени броеви.

Ваша задача е да го пронајдете најголемиот број чиј збир на цифрите е парен број.

### Влез

- Цел број `n`.
- `n` трицифрени броеви.

### Излез

Да се испечати најголемиот трицифрен број чиј збир на цифрите е парен број.
