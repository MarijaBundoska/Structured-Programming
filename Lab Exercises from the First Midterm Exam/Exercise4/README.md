## Exercise 4 - Calculating the New Difference Between Two Numbers

Write a program in which the user enters two integers. The program should calculate their average. Then, it should increase the first number by the value of the average and decrease the second number by the same value. Finally, print the new difference between the numbers.

## Задача 4 - Пресметување на новата разлика меѓу два броја

Да се напише програма во која корисникот внесува два цели броја. Програмата треба да ја најде нивната средна вредност. Потоа, програмата треба да го зголеми првиот број за вредноста на таа средна вредност, а вториот број да го намали за истата вредност. На крајот, да се испечати новата разлика меѓу броевите.
