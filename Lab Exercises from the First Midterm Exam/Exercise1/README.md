## Exercise 1 - Calculating a Student's Average Grade

Write a C++ program to calculate the average grade of a given student.

The input consists of five integers representing the student's grades in one semester.

**Note:** The average must be represented as a `float`.

## Задача 1 - Пресметување просек на оценки на студент

Напишете C++ програма со која ќе пресметате просек на оцените на даден студент.

На влез се вчитуваат пет цели броеви претставувајќи ги оцените на студентот во еден семестар.

**Напомена:** Просекот да се претстави како `float`.


## Test Cases

**Expected output:**
