## Exercise 20 - Checking Whether Three Integers Are All Equal or All Different

Write a program that reads three integers. Print `1` if all three numbers are equal or if all three numbers are different. Otherwise, print `0`.

## Задача 20 - Проверка дали три броеви се исти или различни

Да се напише програма во која се внесуваат три цели броеви. Да се отпечати `1` доколку сите 3 броеви се исти или доколку сите 3 броеви се различни. Во спротивно да се отпечати `0`.


## Test Cases


### Test Case 1

**Input:**
```text
7 7 7
```
**Expected output:**

```text
1
```



### Test Case 2

**Input:**
```text
1 2 3
```
**Expected output:**

```text
1
```





### Test Case 3

**Input:**
```text
0 0 7
```
**Expected output:**

```text
0
```






### Test Case 4

**Input:**
```text
-2 0 2
```
**Expected output:**

```text
1
```
