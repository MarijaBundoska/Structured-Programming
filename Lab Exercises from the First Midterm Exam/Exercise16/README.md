## Exercise 16 - Checking Whether the Digits Are in Strictly Increasing Order

Read a four-digit number from standard input. Print `1` if the digits of the number are in strictly increasing order; otherwise, print `0`.

## Задача 16 - Проверка дали цифрите се во строго растечки редослед

Од стандарден влез се чита четирицифрен број. Да се испечати `1` доколку цифрите во бројот се во **строго растечки** редослед, во спротивно да се испечати `0`.



## Test Cases


### Test Case 1

**Input:**
```text
1234
```
**Expected output:**

```text
1
```


### Test Case 2

**Input:**
```text
5567
```
**Expected output:**

```text
0
```



### Test Case 3

**Input:**
```text
4953
```
**Expected output:**

```text
0
```




### Test Case 4

**Input:**
```text
6789
```
**Expected output:**

```text
1
```
