## Exercise 18 - Checking the Order of Three Integers

Write a program that reads three integers. If the numbers are in ascending order, print `1`. If the numbers are in descending order, print `-1`. Otherwise, print `0`.

## Задача 18 - Проверка на редоследот на три цели броеви

Да се напише програма во која се внесуваат три цели броеви. Доколку внесените броеви се во растечки редослед да се испечати `1`, а доколку се во опаѓачки редослед да се испечати `-1`, во спротивно да се испечати `0`.


## Test Cases


### Test Case 1

**Input:**
```text
10 15 20
```
**Expected output:**

```text
1
```


### Test Case 2

**Input:**
```text
100 10 1
```
**Expected output:**

```text
-1
```




### Test Case 3

**Input:**
```text
1 10 10
```
**Expected output:**

```text
0
```




### Test Case 4

**Input:**
```text
-2 0 2
```
**Expected output:**

```text
1
```
