## Exercise 10 - Swapping Two Numbers

Write a program in which the user enters two integers. The program should swap their values, meaning that the first number takes the value of the second, and the second number takes the value of the first. Print the difference between the numbers before and after the swap.

**Instructions:** Use a temporary variable to swap the numbers.

## Задача 10 - Замена на вредностите на два броја

Да се напише програма со која корисникот внесува два цели броја, а програмата ќе изврши замена на броевите, односно првиот број ќе ја земе вредноста на вториот, а вториот ќе ја земе вредноста на првиот. Притоа да се испечати разликата на броевите пред и по направената замена.

**Упатство:** За да направите замена на броевите, користете привремена променлива.


## Test Cases

**Input:**
