Write a program in which four numbers are entered. If the sum of the first two numbers is an even number and the sum of the last two numbers is an odd number, print 1, otherwise print 0.

## Test Cases


### Test Case 1

**Input:**
```text
3 5 1 2
```
**Expected output:**

```text
1
```



### Test Case 2

**Input:**
```text
6 4 7 3
```
**Expected output:**

```text
0
```


### Test Case 3

**Expected output:**

```text
0
```
