## Exercise 17 - Comparing the Sums of Digits of Two Numbers

Write a program that reads one four-digit number and one three-digit number. Print `1` if the sum of the digits of the first number is greater than the sum of the digits of the second number; otherwise, print `0`.

## Задача 17 - Споредување на сумите на цифрите на два броја

Да се напише програма во која што се внесува еден четирицифрен и еден трицифрен број. Да се отпечати `1` доколку сумата на цифрите на првиот број е поголема од сумата на цифрите на вториот број, во спротивно `0`.
