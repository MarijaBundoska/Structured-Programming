# Task 14 - Matrix Transformation

### Description

Write a program that reads a matrix `A` of integers with `N` rows and `2 * N` columns (`N` is not greater than 50).

The program should transform the input matrix into a new matrix `B` by moving all elements to the right of the `N`-th column below the `N`-th row.

In other words, the original matrix with dimensions `N` rows and `2 * N` columns should be transformed into a matrix with `2 * N` rows and `N` columns.

### Example

For `N = 3`:

```text
3
```

# Task 14 - Трансформација на матрица

### Опис

Да се напише програма во која се вчитува матрица од цели броеви `A` со `N` редици и `N * 2` колони (`N` не е поголемо од 50).

Програмата треба да ја трансформира вчитаната матрица во нова матрица `B`, така што сите елементи десно од `N`-тата колона ќе ги префрли под `N`-тата редица.

Односно, од матрица со димензија `N` редици и `2 * N` колони ќе се добие матрица со `2 * N` редици и `N` колони.
