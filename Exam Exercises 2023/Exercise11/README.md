# Exercise 11 - Digits Sorted by ASCII Code

## Description

From standard input, sequences of characters are read until the character `#` is read.

Write a program in which, for each read line, the number of digits in that line is printed, followed by the character `:`, and then the digits themselves sorted in ascending order according to their ASCII code.

The sequences of characters are not longer than 100 characters.

---

# Задача 11 - Цифри подредени според ASCII кодот

## Опис

Од стандарден влез се читаат низи од знаци сè додека не се прочита знакот `#`.

Да се напише програма во која за секој прочитан ред ќе се отпечати бројот на цифри во тој ред, знакот `:`, па самите цифри подредени според ASCII кодот во растечки редослед.

Низите од знаци не се подолги од 100 знаци.
