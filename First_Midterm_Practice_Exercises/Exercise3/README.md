## Exercise 3 - Number with the Largest Sum of Proper Divisors

Write a program that reads a natural number `n` from standard input.

Among all natural numbers smaller than `n`, find and print the number whose proper divisors have the largest sum.

The sum of proper divisors of a number includes all its positive divisors except the number itself.

## Задача 3 - Број со најголем збир на вистински делители

Од стандарден влез се чита еден природен број `n`.

Меѓу природните броеви помали од `n`, да се најде и да се испечати бројот чиј збир на делителите е најголем.

При пресметувањето на збирот на делителите на даден број, не се зема предвид самиот број.
