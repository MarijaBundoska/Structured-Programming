## Exercise 1 - Smallest Number with Only Even Digits

A *blag number* is a number consisting only of even digits (`0, 2, 4, 6, 8`).

Write a program that reads two integers, `m` and `n`, representing the beginning and the end of an interval. The program should find and print the smallest *blag number* within the given interval.

If no such number exists, print `NE`.

## Задача 1 - Најмал благ број во даден опсег

Благ број е број што е составен само од парни цифри (`0, 2, 4, 6, 8`).

Да се напише програма во која од тастатура се внесуваат два цели броја, `m` и `n`, кои го означуваат почетокот и крајот на опсегот. Програмата треба да го најде и да го испечати најмалиот благ број во зададениот опсег.

Ако не постои таков број, да се испечати `NE`.
