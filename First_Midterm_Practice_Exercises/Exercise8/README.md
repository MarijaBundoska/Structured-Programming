## Exercise 8 - Finding the Nearest Totally Different Number

### Description

Read two integers, `N` and `X`, from standard input.

Find the largest number smaller than `N` that is **totally different** from the number `X`.

A number is totally different from another number if and only if none of its digits appears in the other number.

**Note:** The problem must be solved without using arrays or matrices.

## Задача 8 - Наоѓање на најблискиот тотално различен број


### Опис

Од стандарден влез се внесуваат два цели броја `N` и `X`.

Треба да се најде најголемиот број помал од `N` кој е **тотално различен** од бројот `X`.

Еден број е тотално различен од друг број ако и само ако во него не се појавува ниту една од цифрите на другиот број.

**Забелешка:** Задачата треба да се реши без употреба на низи и матрици.
