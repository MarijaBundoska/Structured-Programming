## Exercise 6 - Recursive Number Sequence with Step 3

For a given number `n`, print the following sequence using recursion, without using any loop statements:

`n`, `n-3`, `n-6`, `n-9`, ..., `n-9`, `n-6`, `n-3`, `n`

Use spaces to separate the numbers when printing the sequence.


## Вежба 6 - Рекурзивна секвенца од броеви со чекор 3

За даден број `n`, да се испечати следнава секвенца со помош на рекурзија, без користење наредби за повторување:

`n`, `n-3`, `n-6`, `n-9`, ..., `n-9`, `n-6`, `n-3`, `n`

При печатењето на секвенцата, броевите треба да бидат разделени со празни места.
