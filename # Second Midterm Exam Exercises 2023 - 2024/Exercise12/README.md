## Exercise 12 - Finding the First Uppercase Letter Recursively

Given a string of characters with a maximum length of `100` characters (entered from the keyboard), find and return the first uppercase letter using a recursive function. Print the found letter on the screen. If there is none, the function should return the `'\0'` character.


## Задача 12 - Пронаоѓање на првата голема буква со рекурзија

За дадена низа од знаци со големина од максимум `100` знаци (се внесува од тастатура) да се пронајде и врати првата голема буква со помош на рекурзивна функција. Пронајдената буква да се испечати на екран. Доколку нема, функцијата потребно е да го врати знакот `'\0'`.
