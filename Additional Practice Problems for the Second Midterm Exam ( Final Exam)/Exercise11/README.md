## Exercise 11 - Transforming Arrays by Shifting Elements

Read an integer **M** from standard input, followed by **M arrays of integers**. For each array, first read the number of elements **N** (**N ≤ 100**), followed by the elements of the array.

Each array must be transformed according to the following rules:

- If the first element of the array is a positive number, shift all elements of the array, including the first element, to the right by as many positions as the value of that element. Fill the empty positions created by the shift with zeros.
- If the first element of the array is a negative number, shift all elements of the array, including the first element, to the left by as many positions as the absolute value of that element. Fill the empty positions created by the shift with zeros.

The number of elements in the array must remain unchanged after shifting.

Finally, print the transformed arrays and the number of input arrays that have become empty, meaning that all their elements are zero after the transformation.

The transformation of each array must be implemented in a separate function. Solutions that do not use a function will receive a maximum of 40% of the points.

**Explanation of the Second and Third Examples**

In the second example, only one array with 5 elements is read: `1, 2, 3, 4, 5`. The first element is `1` (positive), so the elements are shifted one position to the right:

```text
_, 1, 2, 3, 4
```

The empty position is filled with `0`, resulting in:

```text
0 1 2 3 4
```

In the third example, only one array with 5 elements is read: `-2, -3, -4, -5, -6`. The first element is `-2` (negative), so the elements are shifted two positions to the left:

```text
-4, -5, -6, _, _
```

The empty positions are filled with zeros, resulting in:

```text
-4 -5 -6 0 0
```

## Задача 11 - Трансформирање на низи со поместување на елементите

Од тастатура се внесува цел број **M**, а потоа **M низи од цели броеви**. За секоја низа прво се внесува бројот на елементи **N** (**N ≤ 100**), а потоа и елементите на низата.

Секоја од внесените низи треба да се трансформира според следниве правила:

- Ако првиот елемент од низата е позитивен број, сите елементи од низата, вклучувајќи го и првиот, се поместуваат надесно за онолку места колку што е вредноста на првиот елемент. Празнините што ќе настанат се пополнуваат со нули.
- Ако првиот елемент од низата е негативен број, сите елементи од низата, вклучувајќи го и првиот, се поместуваат налево за онолку места колку што е апсолутната вредност на првиот елемент. Празнините што ќе настанат се пополнуваат со нули.

При поместувањето, бројот на елементите во низата останува непроменет.

На крајот треба да се испечатат трансформираните низи, како и бројот на влезни низи што останале празни, односно по трансформацијата имаат само елементи со вредност нула.

Трансформацијата на низите треба да се реализира во посебна функција. Решенијата без користење функција ќе бидат оценети со најмногу 40% од поените.

**Објаснување на вториот и третиот пример**

Во вториот пример се вчитува само една низа со 5 елементи: `1, 2, 3, 4, 5`. Првиот елемент е `1` (позитивен број), па елементите се поместуваат за една позиција надесно:

```text
_, 1, 2, 3, 4
```

Потоа празнината се пополнува со `0`, па низата ги содржи елементите:

```text
0 1 2 3 4
```

Во третиот пример се вчитува само една низа со 5 елементи: `-2, -3, -4, -5, -6`. Првиот елемент е `-2` (негативен број), па елементите се поместуваат за две позиции налево:

```text
-4, -5, -6, _, _
```

Потоа празнините се пополнуваат со нули, па низата ги содржи елементите:

```text
-4 -5 -6 0 0
```
