## Exercise 2 - Square Matrix Filled in a Zigzag Column Pattern

### Description

Read a natural number `N` (`N < 400`) from the keyboard.

Write a program that constructs a square matrix containing the numbers from `1` to `N` in ascending order, following this pattern: fill the first column from top to bottom, then continue with the second column from bottom to top, then the third column from top to bottom, and so on.

Choose the **smallest possible square matrix dimension** that can accommodate all the numbers from `1` to `N`. If there are any remaining empty cells, fill them with zeros.

**Example**

**Input:**
```text
22
```

**Output:**
```text
1 10 11 20 21
2 9 12 19 22
3 8 13 18 0
4 7 14 17 0
5 6 15 16 0
```

## Задача 2 - Квадратна матрица со броеви во цик-цак редослед по колони

### Опис

Од тастатура се чита природен број `N` (`N < 400`).

Да се напише програма што формира квадратна матрица која ги содржи броевите од `1` до `N` по растечки редослед на следниот начин: првата колона се пополнува од горе надолу, втората од долу нагоре, третата од горе надолу итн.

Да се избере **најмалата можна димензија на квадратната матрица** во која ќе се сместат сите броеви до `N`. Доколку останат празни места, тие да се пополнат со нули.

**Пример**

**Влез:**
```text
22
```

**Излез:**
```text
1 10 11 20 21
2 9 12 19 22
3 8 13 18 0
4 7 14 17 0
5 6 15 16 0
```
