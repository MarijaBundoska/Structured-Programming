# Exercise 15 - Min-Max Normalization of Matrix Columns

## Problem Description

Read a matrix with `m` rows and `n` columns from standard input. First, read the numbers `m` and `n`, followed by the elements of the matrix.

Perform **min-max normalization** on each column of the matrix. Each element in a column should be replaced with its normalized value, calculated using the formula:

<img width="80" height="39" alt="image" src="https://github.com/user-attachments/assets/fb55029e-1b97-4bd0-a8db-f3fbee413637" />

where `x` is an element in the column, `max` is the largest element in that column, and `min` is the smallest element in that column.

Print the transformed matrix to the screen.

**Example Explanation:**

The elements of the 0-th column are: `1, 6, 11, 16, 21`. The minimum element is `1`, and the maximum element is `21`.

Each of the five elements is transformed as follows:

- `(1 - 1) / (21 - 1) = 0 / 20 = 0.00`
- `(6 - 1) / (21 - 1) = 5 / 20 = 0.25`
- `(11 - 1) / (21 - 1) = 10 / 20 = 0.50`
- `(16 - 1) / (21 - 1) = 15 / 20 = 0.75`
- `(21 - 1) / (21 - 1) = 20 / 20 = 1.00`

# Задача 15 - Min-max нормализација на колоните во матрица

## Опис на задачата

Од стандарден влез се вчитува матрица со `m` редици и `n` колони. Прво се вчитуваат броевите `m` и `n`, а потоа и елементите на матрицата.

Да се изврши **min-max нормализација** на секоја колона од матрицата, односно секој елемент во секоја колона да се замени со нормализираната вредност пресметана според формулата:

<img width="80" height="39" alt="image" src="https://github.com/user-attachments/assets/4ca77236-a657-45ad-9c1c-88e60b2b611f" />

Трансформираната матрица да се испечати на екран.

**Објаснување на примерот:**

Елементите на 0-тата колона се: `1, 6, 11, 16, 21`. Минималниот елемент е `1`, а максималниот елемент е `21`.

Секој од петте елементи ќе се трансформира на следниот начин:

- `(1 - 1) / (21 - 1) = 0 / 20 = 0.00`
- `(6 - 1) / (21 - 1) = 5 / 20 = 0.25`
- `(11 - 1) / (21 - 1) = 10 / 20 = 0.50`
- `(16 - 1) / (21 - 1) = 15 / 20 = 0.75`
