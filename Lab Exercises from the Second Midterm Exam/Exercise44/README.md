## Exercise 44 - Changing the Sign of Main Diagonal Elements

Read an integer **N** from standard input, representing the number of rows and columns of a square matrix. First, read **N**, followed by the **N × N** elements of the matrix.

Write a program that changes the sign of the elements on the main diagonal of the matrix (positive elements become negative and negative elements become positive).

## Задача 44 - Промена на знакот на елементите од главната дијагонала

Од стандарден влез да се прочита квадратна матрица со број на редици и колони **N**. Прво се вчитува бројот **N**, а потоа и **N × N** елементите на матрицата.

Да се промени знакот на елементите од главната дијагонала на матрицата (позитивните да станат негативни и обратно).
