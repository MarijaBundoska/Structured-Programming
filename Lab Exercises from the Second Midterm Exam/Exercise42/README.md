## Exercise 42 - Transforming Array Elements Based on Conditions

Read an integer **N** from standard input. Then, read an array of **N** integers.

Write a program that transforms the elements of the array as follows:
- If an element is an even number, increase it by **3**.
- If an element is an odd number divisible by **5**, decrease it by **2**.

Print the transformed array.

## Задача 42 - Трансформација на елементи во низа според услови

Од стандарден влез се вчитува цел број **N**. Потоа се вчитува низа од **N** цели броеви.

Да се напише програма која ќе ги трансформира елементите на низата на следниот начин:
- Ако елементот е парен број, да се зголеми за **3**.
- Ако елементот е непарен број делив со **5**, да се намали за **2**.

Да се испечати трансформираната низа.
