# Exercise 7 - Checking Whether an Array Is Special

## Problem Description

Read an array of `n` integers. Check whether the array is special. If 50% or more of all numbers at even positions are even numbers, and 30% or less of all numbers at odd positions are odd numbers, then the array is special. Print `1` if the array is special, otherwise print `0`.

---

# Задача 7 - Проверка дали низата е специјална

## Опис на задачата

Се чита низа од n цели броеви. Провери дали низата е специјална. Ако од сите броеви на парни позиции 50% или повеќе се парни броеви, и од сите броеви на непарна позиција 30% или помалку се непарни броеви, тогаш низата е специјална. Испечати 1 ако е низата специјална, испечати 0 ако не е.
