# Exercise 19 - Finding the Largest Odd Digit Using Recursion

## Problem Description

Two integers, `a` and `b`, are read from standard input. Your task is to find the largest odd digit in each number within the interval `[a, b]`.

The function used to find the largest odd digit must be implemented recursively.

**Note:** If a number does not contain any odd digits, print `0`.

Each number and its corresponding digit should be printed in the following format:

`number -> digit`

---

# Задача 19 - Пронаоѓање на најголемата непарна цифра со рекурзија

## Опис на задачата

На стандарден влез се читаат два броја `a` и `b`. Ваша задача е да ја најдете најголемата непарна цифра на секој број во опсегот `[a, b]`.

Функцијата за наоѓање на најголемата непарна цифра мора да биде рекурзивна.

**Напомена:** Ако бројот нема непарни цифри, се печати `0`.

Печатењето на секој број и неговата цифра е во следниот формат:

`број -> цифра`
