# Exercise 18 - Recursive Function to Print a Star Pattern

## Problem Description

Read an integer `N` from standard input. Define a function `form(int n)` that prints a pattern of stars as shown in the image.

**To receive full points for the exercise, the function `form` must be implemented recursively.**

---

# Задача 18 - Рекурзивна функција за печатење форма од ѕвезди

## Опис на задачата

Да се прочита бројот `N` од тастатура. Да се дефинира функција `form(int n)` што ќе испечати форма од ѕвезди како што е прикажано на сликата.

**За да се освојат сите поени од вежбата, потребно е функцијата `form` да биде рекурзивна.**
