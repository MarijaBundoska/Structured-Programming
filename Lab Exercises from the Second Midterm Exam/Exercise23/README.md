## Exercise 23 - Recursive Number Transformation

Write a **recursive function** that transforms a number so that each odd digit is decreased by 1, while even digits are replaced with zero. The function should return the transformed number. Write a main program to test the function.

## Задача 23 - Рекурзивна трансформација на број

Да се напише **рекурзивна функција** преку која бројот ќе се трансформира на тој начин што секоја непарна цифра ќе се намали за 1, а парните цифри ќе бидат заменети со нула. Функцијата треба да го врати трансформираниот број. Да се напише и главна програма која ќе ја тестира работата на функцијата.
