# Exercise 1 - Element Closest to the Mean

## Problem Description

Read an integer `n` from standard input, followed by an array of `n` real numbers. Print the element that is closest to the mean value of the elements in the array.

---

# Задача 1 - Елемент најблиску до средната вредност

## Опис на задачата

Од стандарден влез се чита број `n`, а потоа се чита и низа составена од `n` реални броеви. На екран да се испечати елементот кој што е најблиску до средната вредност на елементите на низата.


## Test Cases


### Test Case 1

**Input:**
```text	
6
64.1 58.0 38.2 9.0 60.5 18.5
```
**Expected output:**

```text
38.20
```



### Test Case 2

**Input:**
```text
7
22.2 36.9 78.2 51.2 2.3 66 21.5
```
**Expected output:**

```text
36.90
```





### Test Case 3

**Input:**
```text
3

```
**Expected output:**

```text
15.25
```






### Test Case 4

**Input:**
```text
5
15.3 4.9 4.56 1.81 2.36
```
